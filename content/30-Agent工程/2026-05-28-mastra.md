# Mastra — TypeScript AI Agent 框架

> [📎 原始仓库](https://github.com/mastra-ai/mastra) | ⭐ 24,453 | 🍴 2,144 | 🐛 Open Issues 466
> [📁 本地源码](../99-工具与参考/repos/mastra/index.md)

## 一句话定位

Mastra 是 Gatsby 原团队打造的 **TypeScript AI Agent 应用框架**，提供从原型到生产所需的完整工具链：Agent 引擎、Workflow 编排、Memory 记忆、MCP 工具、RAG 检索、Evals 评估和可观测性。

---

## 核心概念

### 1. Agent（智能体）

基于 LLM 的自主智能体，能够：
- 使用 **Tools** 调用外部功能
- 内部迭代推理直到满足停止条件
- 支持 **Durable Agent**（可暂停/恢复的持久化 Agent）

### 2. Workflow（工作流）

图结构编排引擎，支持：
- `.then()` 顺序执行
- `.branch()` 分支判断
- `.parallel()` 并行执行
- **Human-in-the-loop**：暂停等待用户输入后继续

### 3. Memory（记忆系统）

给 Agent 提供上下文的能力：
- **Conversation History** 对话历史
- **Working Memory** 工作记忆
- **Semantic Recall** 语义记忆（向量检索）

### 4. MCP（Model Context Protocol）

- 编写 MCP Server，暴露 Agent / Tools / 资源
- 任何支持 MCP 的系统都可以调用

### 5. RAG（检索增强生成）

从 APIs、数据库、文件等来源检索数据，增强 LLM 上下文。

### 6. Evals（评估）

内置评估框架，持续观察、测量和优化 Agent 表现。

## 核心包导出（@mastra/core）

`@mastra/core` 采用细粒度导出设计，支持按需导入：

| 子路径 | 功能 |
|--------|------|
| `@mastra/core/agent` | Agent 定义与运行 |
| `@mastra/core/workflows` | Workflow 编排 |
| `@mastra/core/memory` | 记忆管理 |
| `@mastra/core/llm` | LLM 模型路由 |
| `@mastra/core/tools` | 工具定义 |
| `@mastra/core/mcp` | MCP 客户端/服务端 |
| `@mastra/core/storage` | 持久化存储 |
| `@mastra/core/vector` | 向量存储接口 |
| `@mastra/core/evals` | 评估指标 |
| `@mastra/core/observability` | 可观测性（OpenTelemetry） |
| `@mastra/core/auth` | 认证模块 |
| `@mastra/core/server` | HTTP 服务端 |
| `@mastra/core/deployer` | 部署抽象 |

## 亮点设计

1. **Model 路由层**：统一接口连接 40+ 提供商（OpenAI、Anthropic、Gemini 等）
2. **细粒度模块导出**：按需导入，避免打包体积膨胀
3. **Human-in-the-loop**：通过 Storage 持久化执行状态，支持无限期暂停和恢复
4. **双许可证模式**：核心 Apache 2.0 开源，企业功能在 `ee/` 目录下源码可用
5. **Y Combinator W25**：获得 YC 孵化的 Agent 框架
